## The problem with data-only training

A network trained only to match reference solutions can fit its training data well and still produce outputs that break the rules of the system, such as violating a power balance equation or a voltage limit. Nothing in a plain data loss tells the model those rules exist.

## The idea

A physics-informed neural network adds the rules to the loss. The model is penalised both for being far from the reference and for violating the equations:

$$
\mathcal{L} = \mathcal{L}_{\text{data}} + \lambda_{1}\,\mathcal{L}_{\text{balance}} + \lambda_{2}\,\mathcal{L}_{\text{limits}}
$$

The weights $\lambda_1$ and $\lambda_2$ control how strongly each rule is enforced.

## A minimal sketch in PyTorch

This is an illustration of the structure, not code from a specific project.

```python
import torch

def physics_loss(pred, target, balance_residual, limit_violation, l1=1.0, l2=1.0):
    data = torch.mean((pred - target) ** 2)
    balance = torch.mean(balance_residual ** 2)
    limits = torch.mean(torch.relu(limit_violation) ** 2)
    return data + l1 * balance + l2 * limits
```

## What this does not guarantee

Penalty terms push predictions toward feasibility but do not enforce it. A small penalty is not zero violation, so constraint violations should always be measured on held-out data and reported.
